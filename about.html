About the Project

Spam Detect PH is a Machine Learning-powered web application designed to combat the rising tide of SMS spam, scams, and smishing attacks in the Philippines. It combines traditional Neural Networks with modern Generative AI to provide deep insights into local SMS threats.

🛠️ Technical Architecture

Frontend

  • Vanilla JavaScript & HTML5
  • OCR via Tesseract.js (Client-side)
  • Hosted on Vercel

Backend

  • Python (Flask API)
  • Scikit-Learn (MLP Inference)
  • Google Gemini 2.5 Flash (Generative AI)
  • Hosted on Render

🧠 Model Selection & Experiments

The core system runs on a Multi-Layer Perceptron (MLP). We selected this model after extensive benchmarking against 8 other algorithms (including Random Forest, SVM, and Naive Bayes) and advanced Transformers (DistilBERT).

Fig 1. Model Accuracy Leaderboard

Why not DistilBERT?

While we trained a DistilBERT (Transformer) model, we found that MLP (98.2%) offered comparable accuracy to DistilBERT (~95%) but with significantly faster inference times and lower computational cost, making it ideal for a free web deployment.

🔍 Explainable AI (LIME)

To ensure transparency ("White Box AI"), we utilized LIME (Local Interpretable Model-agnostic Explanations). This technique highlights exactly which words in a message triggered the spam detection.
